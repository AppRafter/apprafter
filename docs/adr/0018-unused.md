# ADR 0018: Unused

## Status

Unused.

This ADR number was reserved during early discussions for a multi-tenancy decision. The final multi-tenancy ADR was renumbered to 0023 after additional unrelated decisions consumed earlier numbers. 0018 is kept in the sequence as `Unused` to preserve linear numbering and avoid confusion.

If a future architectural decision needs an ADR slot before 0025, this number may be reused with a clear `Replaces ADR 0018 (unused slot)` note.
