# Backstage tier-1 manifest example

`example.yaml` is the deterministic rendering of
`cli-providers::k8s::backstage_manifests::backstage_manifests_yaml(
"backstage.example.com",
"ghcr.io/apprafter/backstage:placeholder")`. It's the same YAML
`platform-cli cluster-bootstrap` applies when
`spec.backstage.domain` is set in the Infrastructure manifest.

Use it as a starting point when you're populating your bootstrap
Git repo (`spec.argocd.bootstrapRepo`):

1. Copy `example.yaml` into your repo at the path Argo CD watches.
2. Replace the placeholder hostname (`backstage.example.com`) with
   your real FQDN.
3. Replace the placeholder image
   (`ghcr.io/apprafter/backstage:placeholder`) with the image you
   built from your `@backstage/create-app` scaffold.
4. Commit + push. Argo CD will sync.

Refresh the example by running:

```sh
cd cli && \
  cargo run --quiet -p cli-providers --example backstage_example \
    2>/dev/null \
  | sed -n '/^# Generated by AppRafter/,$p' \
  > ../manifests/tier-1/backstage/example.yaml
```
